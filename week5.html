Introduction

This week focused on introducing 3D design and assembly using SolidWorks. The main objectives were to learn how to create 3D models, assemble multiple components, and generate technical drawings. SolidWorks is a powerful CAD software widely used in engineering and design fields for creating detailed 3D models and assemblies.

Process Documentation

PART MODELING
  • Part modeling in SolidWorks is the process of creating individual components from technical drawings. Each part starts with a 2D sketch created on a reference plane, where dimensions and constraints are applied to match the drawing. The sketch is then converted into a 3D object using features such as extrude, revolve, cut, fillet, and chamfer. Materials are assigned to the part to define its physical properties, such as weight and strength.

  • ASSEMBLY
  • Assembly modeling involves combining individual parts to form a complete product. The modeled parts are inserted into an assembly file and positioned using mates such as coincident, concentric, parallel, and distance mates. These mates define how parts relate to each other and restrict movement where necessary. Assembly modeling allows the designer to check fit, alignment, clearances, and overall functionality before manufacturing.

    • MAKE DRAWING FROM ASSEMBLY
  • Working drawings are created from the modeled parts and assemblies to guide manufacturing and fabrication. SolidWorks automatically generates 2D views such as front, top, side, section, and isometric views from the 3D models. Dimensions, tolerances, materials, and notes are added to clearly communicate design intent. These drawings ensure that components can be accurately manufactured and assembled according to specifications.
